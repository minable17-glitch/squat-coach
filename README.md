# 자세 코치 (스쿼트 · 푸시업)

카메라로 스쿼트 자세를 실시간으로 봐 주는 체육 수업용 웹앱이에요. 연습, 게임(30초·60초 챌린지), 형성평가(5회) 모드가 있어요.

## 올리는 방법 (택 1)

카메라는 **https 주소**에서만 켜져요. 이 폴더를 통째로 올려 주세요.

- **Vercel**: vercel.com → Add New → Project → 이 폴더를 끌어다 놓기 (또는 GitHub 저장소에 넣고 연결)
- **GitHub Pages**: 저장소에 폴더를 올리고 Settings → Pages에서 켜기
- **Netlify**: app.netlify.com/drop 에 폴더를 끌어다 놓기

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 자세 분석 |
| `lib/` | 자세 인식 라이브러리 (Google MediaPipe Tasks Vision 0.10.14, Apache 2.0) |
| `models/pose_landmarker_lite.task` | 자세 인식 모델 (Google MediaPipe, Apache 2.0) |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면에 앱처럼 설치 |
| `sw.js` | 한 번 받은 파일을 기기에 저장해 다음부터 빨리 열기 |

`lib/`과 `models/`를 함께 올리면 학교 망에서 jsdelivr.net이나 storage.googleapis.com이 막혀 있어도 동작해요. `index.html`만 올리면 그 두 곳에서 받아 와요.

## 판정 기준 (index.html 안에서 바꿀 수 있어요)

- 깊이(옆에서): 무릎 각도 95° 이하면 허벅지 수평, 초보 기준은 약 117°
- 상체(옆에서): 수직에서 50° 넘게 숙이면 ✗
- 무릎 모임(앞에서, 시험 중): 앉았을 때 무릎 너비가 발목 너비의 80%보다 좁으면 ✗
- 뒤꿈치: 정확도가 낮아 참고 알림만, 점수에는 넣지 않음
- 평가 등급: 5회 중 4회 이상 잘함, 2~3회 보통, 그 아래 노력 필요

영상은 기기 안에서만 처리하고 저장하거나 보내지 않아요.

## 무릎 위치 판정 (옆에서 찍을 때)

정강이(발목→무릎)가 수직에서 앞으로 기운 각도로 무릎이 발끝보다 많이 나왔는지 봐요. 화면 위에서 고를 수 있어요.

- 무릎 엄격: 38°보다 기울면 인정 안 됨
- 무릎 보통(기본): 45°보다 기울면 인정 안 됨
- 무릎 판정 끄기

바른 자세로 한 스쿼트만 개수로 인정해요(깊이, 상체, 무릎 위치, 앞에서 찍을 때는 무릎 모임).

## 주소로 바로 열기

- 연습: `?mode=practice`
- 게임: `?mode=game`
- 평가: `?mode=test`
- 앞에서 찍기: `&view=front`

## 푸시업

- 화면 위(설정)에서 운동을 **푸시업**으로 바꾸거나 주소에 `?ex=pushup`을 붙여요.
- 옆에서 찍기: 팔꿈치 각도로 깊이(팔꿈치 100° 이하), 어깨-엉덩이-발목 각도로 몸 일직선(163° 미만이면 인정 안 됨)을 봐요.
- 앞에서 찍기: 어깨가 손목 쪽으로 절반 넘게 내려오면 깊이 인정. 몸 일직선은 볼 수 없어요.
- 팔을 펴고 엎드려 1초 멈추면 준비가 끝나요.

## 온라인 대결

- 모드에서 **대결**을 고르고 별명을 넣은 뒤 **방 만들기**를 누르면 4자리 방 번호가 나와요. 친구는 그 번호로 들어와요. 초대 링크(`?room=1234`)를 보내도 돼요.
- 먼저 들어온 사람이 방장이에요. 방장이 운동(스쿼트·푸시업)과 시간(30·60초)을 정하고 시작을 눌러요.
- 2명이면 1대1 막대 점수판, 3명 이상이면 순위표가 보여요. 바른 자세로 한 것만 개수로 인정돼요.
- 통신은 Supabase Realtime을 써요. **별명과 개수만** 주고받고 저장하지 않아요. 영상은 보내지 않아요. 실명 대신 별명을 쓰도록 안내해 주세요.
- 학교 망에서 `supabase.co`가 막혀 있으면 대결만 안 돼요. 연습·게임·평가는 그대로 돼요.
- `lib/supabase.js`는 supabase-js 2.45.4 (MIT)예요.
